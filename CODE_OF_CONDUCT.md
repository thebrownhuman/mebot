# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By taking part in issues, pull requests, discussions or any other project space, you agree to
it.

In short: be welcoming and respectful, criticise ideas rather than people, and assume good
faith. Harassment, personal attacks, sexualised language or imagery, and publishing anyone's
private information are not acceptable.

**Reporting.** Contact the maintainer privately through a GitHub private security advisory
(Security → Report a vulnerability, marked as a conduct report) or at
`<conduct-contact-email>` (set by the maintainer before the repository goes public).
Reports are handled confidentially. Enforcement follows the Contributor Covenant's
enforcement guidelines: correction, warning, temporary ban, permanent ban.
